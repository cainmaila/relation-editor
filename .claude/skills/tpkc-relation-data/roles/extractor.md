# ① 抽取員

一份來源派一個，並行。用 general-purpose subagent（要寫 facts 檔；Explore 型不能寫檔）。

**任務**：只讀這一份來源，把裡面寫到的事實抽出來。不對應類型、不推論、不看現有資料。

**輸入**：來源路徑或原文、出處名稱（檔名或「使用者口述 YYYY-MM-DD」）。

**產出**：寫 `data-staging/_work/facts/<出處>.md`，一條事實一行：

```
- [實體] <來源上的名稱> ｜屬性：<欄位=值, …> ｜出處：<檔名:列/頁> ｜原文：「…」
- [關係] <A> → <B> ｜來源用詞：<供電/接到/位於…> ｜出處：… ｜原文：「…」
- [不明] <看不懂或可能有意義的段落> ｜出處：… ｜原文：「…」
```

**禁止**：補來源沒寫的名稱、關係、方向；把多個實體合併成一個（同物異名留給對應員判斷）。
