# 關係編輯器（relation-editor）

## 這是什麼

機房／IDC 關係圖的瀏覽與局部編輯工具，macOS 桌面 app。全圖用 3D 宇宙呈現上萬個節點，編輯頁用 2D 卡片圖在最多 200 個節點的工作區內修改。

## 安裝與開啟

1. 取得 `.dmg`，開啟後把 app 拖進「應用程式」。
2. app 沒有簽章，第一次開啟請對 app 按右鍵 →「開啟」，再在跳出的對話框按「開啟」，以通過 macOS Gatekeeper。之後可直接開啟。

## 資料夾與存檔

- 第一次開啟用內建範例（2,066 節點的 2F 全棟示意資料）。
- 按「儲存」（⌘S）選一個資料夾，編輯結果就以 CSV 寫進去；之後開啟會自動讀那個資料夾，「開啟…」可換資料夾。
- 儲存前會先驗證資料，不過就不寫並顯示原因。只會寫入、覆蓋同名檔，不會刪資料夾裡其他檔案。沒有改動時「儲存」不可按。
- 資料夾讀不到或內容有誤時，錯誤頁會說明原因並取消資料夾設定，重新開啟改回內建範例。
- 有未儲存的改動時，關閉視窗或開啟別的資料夾會先確認。
- 詳情欄修改是草稿：按「儲存」才寫回圖；未儲存時會顯示「尚未儲存：切換選取或離開會捨棄（不會自動保存）」，切換選取就捨棄草稿，不另外跳確認框。

## 畫面操作

兩個畫面（頂列「全圖」／「編輯頁」）：

- **全圖（3D）**：看完整標準圖。拖曳旋轉、滾輪縮放、點節點選取；⌘K 全量搜尋（結果分頁、可跨頁勾選加入編輯頁）；系統開關（⌥＋點只看一個系統）；「找客戶」沿完整標準圖追查，結果分頁並標示分析版本；狀態列顯示版面整理進度、「全景」（只移相機）與「重新整理版面」（重新跑版面）。
- **編輯頁（2D）**：只顯示工作區成員。新增／修改／刪除節點與邊、拖曳卡片連線、右鍵選單；「移出工作區」只是離開工作區，不刪資料（立即生效）。

## 工作區規則

- 工作區上限 200 個節點／1,000 條誘導邊，加入是整批原子判斷：超過就整批拒絕並說明，不會只加一部分。
- 刪除節點或邊是永久刪資料，沒有復原：詳情、右鍵、浮動工具列、⌫ 一律要再按一次「確認刪除」（取消或 Esc 什麼都不改），節點會說明連帶幾條邊（含工作區外看不到的）。
- IDC 維護的資料與根節點不能刪，直接說明原因、不出現確認。

## 畫面上的顯示上限

縮放只影響「畫出多少」，不改資料、不改搜尋與追查結果。

- 細節球 ≤ 1,000、局部邊 ≤ 2,000（兩端皆細節）、高亮邊 ≤ 2,000、標籤 ≤ 80；被省略的數量顯示在圖例。
- 選取的節點只要在相機前方、遠裁切面以內且所屬系統可見，就一定有標籤（放不下時夾進畫面內）；在相機後方或超出遠裁切面時不畫。其他節點的標籤受 80 個上限與避碰限制，不保證每個都有。
- 選取的邊在高亮上限內一定畫。

## 資料檔（CSV）格式

資料夾結構（相對於資料夾）：

- `index.json`：要載入的 CSV 清單（相對資料夾）。新增或刪除檔案要同步改這裡。
- `nodes/<系統>.csv`：系統為 空間、電力、空調、網路、消防、CCTV，另有 `通用.csv`（通用節點）。欄位 `類型,key,名稱,<屬性...>`；`類型` 必須屬於該系統；`key` 必填、全圖唯一（含 IDC），邊以 key 當起訖；`名稱` 選填、可重複，空白＝顯示 key；屬性空格＝沒有該屬性。屬性欄取該系統各類型的聯集，用不到的留空。
- `edges/<邊類型>.csv`：前三欄 `起點,終點,雙向`（起訖填節點 key；`雙向` 填 `是`，空白＝單向），其餘欄是屬性。
- `idc/nodes/<類型>.csv`、`idc/edges/<類型>.csv`：檔名即類型，節點檔不需 `類型` 欄（欄位 `key,名稱`）；整個資料夾載入為唯讀（由 IDC機櫃配置管理維護，之後會改由另一個系統提供）。

規則：

- 表頭固定欄不符（含舊的 `名稱` 單欄格式）會直接報錯，不相容舊格式。
- 邊檔、idc 檔的檔名必須是系統已有的類型名；新增類型或系統需請開發者加入。
- 格式：UTF-8（Excel 的 BOM 可）、逗號分隔、含逗號或換行的格子用雙引號。
- 資料有誤（未知類型、名稱重複、端點找不到）會顯示錯誤頁，訊息帶檔名與列號。

## 已知限制

- 只支援 macOS；app 沒有簽章。
- 刪除沒有復原。
- 不支援多人協作。
- 50k 節點／100k 邊可操作，但不是正式支援規模。

## 從原始碼執行（第一次 clone）

先裝好：Xcode Command Line Tools（`xcode-select --install`）、Node.js（24 可用）、Rust 1.90 以上（[rustup](https://rustup.rs)）。pnpm 用 Node 內建的 corepack 啟用即可。

```sh
git clone git@github.com:cainmaila/relation-editor.git
cd relation-editor
corepack enable   # 啟用 pnpm（版本由專案指定）
pnpm install
```

### 1. 開發驗證

```sh
pnpm tauri dev    # 開桌面 app，改程式碼會即時更新；第一次要編譯 Rust，需數分鐘
```

只看畫面、不需存檔時可用 `pnpm dev`，在瀏覽器開 http://localhost:5173（瀏覽器模式不能存檔，重新整理就還原）。

### 2. 打包

```sh
pnpm tauri build
```

產出在 `src-tauri/target/release/bundle/`：`macos/` 裡是 `.app`，`dmg/` 裡是 `.dmg`。沒有簽章，開啟方式見上方「安裝與開啟」。

開發者請看 `docs/agents/development.md`。
